# 臺灣台語 B2 備考 WebApp

這是一個單機 PWA，供手機每日學習使用，目標是 2027/03/07 的教育部臺灣台語語言能力認證 B 卷（B2）。學習紀錄只存在手機本機（IndexedDB），不需要伺服器或帳號。

## 功能
- **今日**：考試倒數、所在階段、到期複習與今日新卡（依期程自動分配）、當日的題型練習。
- **學習區**：
  - 臺羅與變調：聲調表、變調規則、數字調輸入說明。
  - 語詞 01／02：共 856 詞，每 50 詞一個單元。
  - 語句 01／02：共 840 句，分 16 類。
  - 文章：59 篇，附全文朗讀、可切換的臺羅注音、聽力模式、詞彙與文法說明。
- **複習區**：分到期、不熟、再複習、錯題四個池，每個池都可以選閃卡或測驗。
- **測驗區**：依 B 卷四科分類。
  - 閱讀：語詞語法、語法專項、克漏字、文章理解。
  - 聽力：聽句選義、聽詞選字、演說聽解。
  - 書寫：聽寫拼音、聽寫漢字、語句書寫、文章寫作。
  - 口語：跟讀、情境對話、看圖講話、文章朗讀、口語表達。
  - 另有臺羅練習、官方範例卷，以及 40 題、50 分鐘的閱讀模擬考。
- **紀錄**：統計、錄音作品、寫作紀錄、離線音檔下載、設定與備份、資料來源與授權。

## 複習排程
- 間隔依序為：當次 10 分鐘 → 1 → 2 → 4 → 7 → 15 → 30 → 60 天。
- 按鈕的作用：
  - **已熟記**：進到下一階段。新卡第一次就按已熟記，直接跳到 4 天。
  - **再複習**：維持原階段，間隔減半，最少 1 天。
  - **不熟**：階段歸零，同一輪隔 5 張卡後再出現一次。
- 測驗答對等同按「已熟記」，答錯等同按「不熟」，並記入錯題區。
- 錯題要在**不同的兩天**各答對一次，才會離開錯題區。
- 複習日不會排到考試前一天之後。
- 這組間隔是參考艾賓浩斯遺忘曲線的經驗設定，不是經過實證最佳化的參數。App 會記錄每次作答，日後可以用實際的記得率檢驗與調整。
- 程式在 `app/src/lib/scheduler.ts`，測試在 `app/src/lib/lib.test.ts`。

## 重建資料
資料前處理在 Mac 上執行，需要 `data-raw/` 和 `Learning Resource/`；這兩個資料夾都不進版控。
```bash
python3 -m venv .venv && .venv/bin/pip install pymupdf
.venv/bin/python pipeline/parse_books.py      # 解析課本 PDF
.venv/bin/python pipeline/fetch_tb_audio.py   # 下載課本音檔（需先執行過 audio_links 擷取）
.venv/bin/python pipeline/build_content.py    # 校正臺羅、連結辭典、抽音檔、輸出 app/public/data
```
`content/report.md` 是比對報告，列出統計、待人工檢查的條目，以及隨機抽樣的 30 筆。

## 開發
```bash
cd app && npm install && npm run dev
```
```bash
cd app && npm test && npm run build
```

## 部署到 GitHub Pages
1. 在 GitHub 建一個 repo，把本資料夾推上去。`.gitignore` 已排除原始 PDF 與 `data-raw/`。
2. 到 repo 的 Settings › Pages，Source 選「GitHub Actions」。
3. 推送到 `main` 後，`.github/workflows/deploy.yml` 會自動測試、建置、部署。

## 在 iPhone 上使用
1. 用 Safari 開啟部署後的網址，點分享 › 「加入主畫面」。加入主畫面後，iOS 不會因 7 天未開啟就清除資料。
2. 在 Wi-Fi 下到「紀錄 › 離線音檔」下載音檔：核心約 107 MB、文章約 135 MB、範例卷約 61 MB。
3. 每週到「紀錄 › 設定與備份」匯出一次備份，存到「檔案」App 或 iCloud。
